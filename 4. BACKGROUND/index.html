Background Color

Background color adalah properti CSS yang digunakan untuk mengatur warna latar belakang suatu elemen. Properti ini dapat diterapkan pada berbagai elemen HTML, seperti div, body, dan lainnya.

Contoh penggunaan background-color:

body {
    background-color: lightblue;
}

Dalam contoh di atas, latar belakang halaman web akan berwarna biru muda.
